\# AI-ML-DL Concept Tutor



An interactive Generative AI learning assistant built using Python and Streamlit.



\## Features



\- AI tutor powered by Gemini API

\- Zero-shot, few-shot and chain-of-thought prompting

\- Adjustable temperature

\- Conversational memory

\- Transformer attention visualization

\- Semantic search using Sentence Transformers

\- Image understanding using BLIP

\- Text-to-speech audio summaries

\- Image generation using Stable Diffusion

\- Responsible AI and safety demonstration



\## Technologies Used



Python, Streamlit, Gemini API, PyTorch, Sentence Transformers,

Transformers, BLIP, Stable Diffusion, Matplotlib and gTTS.



\## Installation



1\. Clone this repository.

2\. Create and activate a Python virtual environment.

3\. Install dependencies:



&#x20;  pip install -r requirements.txt



4\. Create a `.env` file and add your Gemini API key:



&#x20;  GEMINI\_API\_KEY=your\_api\_key\_here



5\. Run the application:



&#x20;  streamlit run app.py



\## Intended Use



This project is designed for educational purposes to help students

understand Artificial Intelligence, Machine Learning and Deep Learning.



\## Limitations



AI-generated answers may contain errors. Users should verify important

information. The safety filter is a basic keyword-based demonstration.
